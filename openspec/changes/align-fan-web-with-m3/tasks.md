# Tasks

All code work is in the frontend repository. A `ref` such as `timetable#n8` names a finding in `audit-items.md`. Each fix task starts by reproducing its findings on a local build; a finding that does not reproduce is closed with that note instead of being changed. One pull request per numbered section.
