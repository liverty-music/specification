## ADDED Requirements

### Requirement: A ticket card answers a pointer

A ticket card, which opens the ticket when tapped anywhere outside its buttons and links, SHALL show the shared state layer while a pointer is over it and while it is pressed, as any control does. The ticket number stays the card's keyboard control.

#### Scenario: A ticket card answers a pointer

- **WHEN** the fan moves a pointer over a ticket card
- **THEN** the card shows the hover state layer
